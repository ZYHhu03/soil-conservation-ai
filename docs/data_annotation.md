# 数据构造与标注规范

训练集目标规模约 3000 条高质量问答，覆盖水土保持领域的主要咨询任务。

## 数据分层

| 类别 | 占比 | 重点 |
| --- | ---: | --- |
| 专业术语 | 25% | 术语定义、同义表达、易混概念、面向不同角色的解释 |
| 审批流程 | 25% | 阶段、角色、前置条件、输入输出、异常分支 |
| 材料清单 | 15% | 基础资料、申报材料、缺失材料追问 |
| 技术措施 | 15% | 表土、临时防护、排水、弃土弃渣等措施的适用条件 |
| 场景问答 | 10% | 项目类型、地区、规模、开工状态等槽位组合 |
| 边界与拒答 | 10% | 地区缺失、版本不明、证据冲突、超出知识范围 |

## 单条样本要求

1. 问题只表达一个主要意图；复合问题要明确拆成多个样本，避免模型只记住固定长句。
2. `output` 先给结论，再给适用条件和待补充信息；不能为了完整而捏造政策名称、条款号、日期或审批结论。
3. 涉及政策时效、地区差异和具体材料的样本，记录 `source`、`source_version` 和审核信息。
4. 同一法规原文的改写样本不得跨 train/valid/test；按主题或来源分组后再切分，防止数据泄漏。
5. 至少进行一轮双人复核：术语准确性、流程顺序、适用条件、拒答边界和表达清晰度分别打分；任一关键项不合格就退回修改。

## 评测集冻结原则

评测集独立于训练集维护，规模约 500 条，覆盖常见问题、长尾问题、信息不全、版本冲突和诱导编造五类场景。每条样本保留：

- 期望结论和必须出现的关键点；
- 不应出现的条款/日期/材料；
- 适用条件和需要追问的槽位；
- 来源版本和人工评分记录。

自动指标只用于筛选实验，最终结论要结合人工准确率、拒答正确率、格式合规率和典型错误案例。

## 数据和模型的职责边界

LoRA 负责学习专业表达、任务格式和边界意识；会变化的法规事实、地区适用性和当前有效版本由后续 RAG 检索与引用校验负责。
